# QairuCowork

Находит **общие свободные окна** у студентов из одной группы и помогает договориться о встрече.
Работает двумя лицами одного продукта: **сайт** и **телеграм-бот** — общая база, общее ядро расчёта.

Стек: Next.js 15 (App Router) · TypeScript · Drizzle ORM · PostgreSQL (Supabase) · Tailwind CSS v4
Языки интерфейса: 🇷🇺 русский · 🇰🇿 қазақша · 🇬🇧 english

Обоснование архитектурных решений — в [DESIGN.md](DESIGN.md).

---

## Что это

Каждый **один раз** отмечает, когда он занят — парами, работой, тренировками. Дальше:

- **на сайте**: тепловая карта недели, где цветом видно, сколько человек свободно в каждые полчаса, ползунок кворума и назначение встречи в один клик;
- **в чате**: `/availability` показывает общие окна, `/meeting` собирает встречу с голосованием.

Расписание принадлежит человеку, а не чату: заполнил в боте — видно на сайте, поправил на сайте — работает в боте.

## Деплой на Vercel

### 1. База в Supabase

1. [supabase.com](https://supabase.com) → **New project**, запиши пароль базы.
2. **Project Settings → Database → Connection pooling → Transaction** (порт `6543`) — скопируй строку и подставь в неё пароль. Нужен именно пулер: на Vercel каждый запрос обслуживает отдельная функция, и прямые соединения кончатся раньше трафика.
3. Создай таблицы — **SQL Editor → New query**, вставь содержимое [`drizzle/0000_init.sql`](drizzle/0000_init.sql) и выполни.
   Локальная альтернатива: `DATABASE_URL=… npm run db:push`.

### 2. Проект в Vercel

1. [vercel.com](https://vercel.com) → **Add New → Project** → импортируй репозиторий.
2. В **Environment Variables** добавь как минимум `DATABASE_URL`.
3. **Deploy**. Сайт готов — группы создаются прямо на нём, без Telegram и без регистрации.

### 3. Бот (по желанию)

1. У [@BotFather](https://t.me/BotFather): `/newbot` → скопируй токен.
2. `/setjoingroups` → **Enable** — без этого бота нельзя добавить в группу.
3. Добавь `BOT_TOKEN` в переменные окружения Vercel и **передеплой**.

Больше ничего делать не нужно: после сборки вебхук регистрируется сам на адрес
`https://<домен>/api/telegram/webhook`, а меню команд загружается в Telegram.
Секрет заголовка выводится из токена, поэтому отдельной переменной не требует.

> Проверить или перерегистрировать вручную:
> `https://<домен>/api/telegram/setup?secret=<TELEGRAM_WEBHOOK_SECRET>`.
> Если переменная не задана, секрет — это `sha256("qairu-webhook:" + BOT_TOKEN)`, первые 48 hex-символов;
> его печатает `npm run bot:webhook`.

**Напоминания о встречах.** Их рассылает cron-задача `/api/cron/reminders`, объявленная в
[`vercel.json`](vercel.json). На тарифе Hobby Vercel запускает cron раз в сутки — этого хватает,
чтобы напомнить о встречах ближайшего дня, но не для «за 30 минут». Для минутной точности:
на Pro поменяй расписание на `*/5 * * * *`, либо оставь как есть и повесь любой внешний пингер
(cron-job.org, GitHub Actions) на `https://<домен>/api/cron/reminders?secret=$CRON_SECRET`.

## Локальный запуск

```bash
npm install
cp .env.example .env.local     # Windows: copy .env.example .env.local
npm run dev                    # http://localhost:3000
```

В `.env.local` нужен рабочий `DATABASE_URL` — подойдёт та же база Supabase.
Схему накатывает `npm run db:push`.

Без интернета и без Supabase можно поднять Postgres прямо в процессе:

```bash
node scripts/dev/pg-server.mjs     # PGlite на 127.0.0.1:5544, схема уже накатана
DATABASE_URL=postgresql://postgres:postgres@127.0.0.1:5544/postgres npm run dev
```

Чтобы погонять бота локально, нужен публичный адрес (ngrok, cloudflared):

```bash
NEXT_PUBLIC_SITE_URL=https://ваш-туннель.example npm run bot:webhook
```

## Команды бота

**В личке**

| Команда | Что делает |
|---|---|
| `/schedule`, `/import` | прислать расписание текстом или CSV |
| `/wizard` | заполнить по дням через кнопки |
| `/myschedule` | показать своё расписание |
| `/busy` | разовая занятость: дата, период или «весь день» |
| `/clear` | удалить расписание |
| `/link` | ссылка на веб-версию |

**В группе**

| Команда | Что делает |
|---|---|
| `/setup` | подключить чат (админ) |
| `/join` / `/leave` | войти в список участников / выйти |
| `/members` | кто заполнил, кто нет |
| `/remind` | напомнить незаполнившим одним сообщением (админ) |
| `/availability` | общие окна всех зарегистрированных |
| `/availability @asel @nurbek` | окна вызвавшего + перечисленных |
| `/availability 90` | окна не короче 90 минут |
| `/availability 80%` · `q5` | кворум: свободны 80% участников / хотя бы 5 человек |
| `/meeting @asel` | встреча с опросом, напоминанием и выгрузкой в календарь |
| `/settings` | часы, буфер, чётность недель, напоминание, TZ (админ) |

> **Про команды в группе.** При включённом privacy mode «голая» команда `/availability` доходит до бота только если он был последним ботом, писавшим в чат. Надёжная форма — `/availability@ИмяБота`; Telegram подставляет `@ИмяБота` сам, когда команду выбирают из меню.

## Страницы сайта

| Адрес | Что там |
|---|---|
| `/` | о продукте, создание группы без регистрации |
| `/g/{slug}` | тепловая карта недели, окна с ползунком кворума, встречи, участники, настройки |
| `/g/{slug}/me` | своя сетка: рисуешь занятость мышью или пальцем, либо вставляешь расписание текстом |
| `/g/{slug}/join` | вход по ссылке-приглашению |
| `/g/{slug}/meetings/{id}.ics` | встреча файлом для календаря |

**Аккаунтов нет.** Личность подтверждается токеном в куке — его выдаёт создание группы, переход по
приглашению или команда `/link` в боте. Внутри Telegram Mini App личность берётся из подписанного
`initData`, поэтому веб-пользователь и пользователь бота — один и тот же человек.

## Формат расписания

Одинаково понимается ботом и сайтом:

```
Пн 9:00-10:30 Матан, 13:00-14:30 История
Вт 8:00–9:30
Ср нет пар
Чт 10-11.30; 12:00-13:30 Физика
Пт 9:00-10:30 Алгебра (числитель), 9:00-10:30 Физика (знаменатель)
Сб 18:00-22:00 работа
Жұма 9:00-10:30
Friday 15:00-16:00
```

Дни на трёх языках (полные и сокращённые), разделители `-` `–` `—` `до` `to`, время `9`, `9:00`,
`9.00`, `09-00`, несколько диапазонов через `,` и `;`, слова «нет пар / бос / free»,
«ежедневно / күнде / daily», чётность недель, типы занятости (работа, спорт, экзамен).

Чтобы заработала чётность, задай начало семестра: `/settings semester 01.09.2026` или поле в настройках
группы на сайте. Без этой даты пары «через неделю» **не учитываются** — бот не угадывает, какая неделя сейчас.

Разовая занятость (`/busy` в боте):

```
12.09 14:00-16:00 экзамен
12.09 весь день
15.09-20.09 сессия
15.09-20.09 9:00-14:00 практика
```

CSV: `weekday,start,end,label,parity`.

**Ничего не сохраняется молча** — и бот, и сайт сначала показывают разбор и ждут подтверждения.

## Как считаются окна

Хранится **занятость**, а не свобода: расписание пар человеку легко продиктовать, а перечислить
всё свободное время — нет. Для каждого дня:

0. к каждой занятости добавляется буфер на дорогу, если он задан;
1. слоты человека сливаются (`merge`) — смежные пары 9:00–10:00 и 10:00–11:00 становятся одним блоком, ложного окна не возникает;
2. берётся дополнение до рабочего окна дня (`invert`) — свободное время одного человека;
3. свободные наборы пересекаются (`intersect`, два указателя);
4. окна короче `min_slot` отсеиваются.

**Кворум** и **тепловая карта** считаются заметающей прямой: каждый свободный интервал даёт `+1`
в начале и `−1` в конце, берутся участки со счётчиком ≥ порога. При пороге, равном числу
участников, результат совпадает с пересечением — это закреплено тестом.

Вся логика — чистые функции в `src/core/`, без Telegram, БД и HTTP.

## Тесты

```bash
npm test          # 171 тест
npm run typecheck
```

- **ядро** — алгебра интервалов, кворум, тепловая карта, чётность недель, буфер, часовые пояса, `.ics`;
- **парсер** — три языка, коллизия «сенбі» ⊂ «дүйсенбі», форматы времени, типы занятости, CSV;
- **данные** — весь слой репозитория на настоящем Postgres (PGlite в процессе), схема накатывается тем же файлом миграции, что уедет в Supabase;
- **драйвер** — запросы через `postgres.js` по сетевому протоколу: ловит то, чего не видно на встроенном адаптере;
- **сайт** — состояние группы, сетка, кворум, встречи, настройки, проверка подписи Telegram Mini App (включая подделку, протухший и чужой токен);
- **бот** — сквозные сценарии через настоящий маршрутизатор с заглушкой Bot API: `/setup`, deep-link, мастер расписания, `/busy`, `/availability` с кворумом, полный цикл встречи с голосованием и напоминанием.

## Известные ограничения

- Бот **не видит список участников группы** — ограничение Telegram. В расчёт идут только те, кто прошёл `/join` или кнопку регистрации; `/members` показывает, кого не хватает.
- Бот **не может написать в личку первым**, пока человек не нажал `/start`.
- Часовой пояс задаётся на уровне группы, а не человека.
- Чётность недель требует даты начала семестра.
- Напоминание о встрече ставится, только если время выбрано из общих окон: произвольный текст в дату не разбирается. Точность напоминания ограничена частотой cron (см. раздел про деплой).
- Ссылка `/link` персональная — она открывает расписание своего владельца, пересылать её нельзя.
